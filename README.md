# ChessMate Study

Aplicativo Android para treinamento de xadrez e análise de posições autorizadas.

## Planejamento
- Interface escura, tabuleiro interativo e validação FEN
- Motor Stockfish UCI local, variantes e mate forçado
- Reconhecimento visual de tabuleiros em estudos e partidas contra bots
- Build de APK via GitHub Actions

Status: projeto em desenvolvimento, sem APK compilado ou Stockfish integrado ainda.
