# ChessMate Study — plano técnico

## Implementado no código
- Projeto Android Java mínimo e interface escura.
- Tabuleiro para visualizar uma FEN, com seleção de casas.
- Validação estrutural de FEN com seis campos.
- Workflow de compilação de APK debug.

## Ainda não implementado
- Motor Stockfish nativo para ARM64 e protocolo UCI.
- Jogadas legais, xeque-mate e histórico completo.
- Reconhecimento visual de tabuleiros em imagens de estudo.
- Permissões de captura de tela e sobreposição, serviço flutuante.
- Testes automatizados de posições e testes em dispositivo físico.

## Escopo
Treinamento, partidas contra bots, estudos e análise autorizada; não assistência em partidas ranqueadas contra pessoas.

## Estado de validação
Nenhum teste em Samsung Galaxy A34 5G foi executado. O APK só deve ser considerado compilado quando o workflow concluir com sucesso e publicar o artefato.
